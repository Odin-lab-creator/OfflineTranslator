# Valhalla Translate

Офлайн-переводчик для Android на Google ML Kit.

**Скачать последнюю версию:**
https://github.com/Odin-lab-creator/OfflineTranslator/releases/latest/download/ValhallaTranslate.apk

Каждая сборка из ветки `main` подписывается постоянным ключом (`keystore/release.p12`,
пароль в секрете `SIGNING_KEY_PASSWORD`) и публикуется в Releases, поэтому новые версии
ставятся поверх старых.
