# «72 ЧАСА» — серия 1

`episode1_72_chasa.mp4` — 1080×1920, 120 с, озвучка ElevenLabs (Roger) + процедурная графика, музыка и SFX.

Файлы:
- `voice.mp3` — озвучка; `script.txt` — сценарий построчно;
- `align.py` — привязывает строки сценария к паузам в озвучке → `timings.json` (можно поправить руками);
- `episode1.py` — рендер ролика (`python3 tiktok/series/episode1.py`, ~6 мин на 8 ядрах).

Сцены: пробуждение и рухнувший город → таймер 72:00:00 → Правило №1 (вода, консервы, аптечка, фонарь, батарейки, зарядка, офлайн-карты) →
стук в дверь → Правило №2 (чек-лист) → вторая ночь, две радиопередачи → Правило №3 (слухи) →
SMS «НЕ СМОТРИ В ОКНО», скрип, силуэт → финал «станешь тем, от кого выживают» → анонс серии 2 «Чужие у двери».
Сквозной HUD — обратный отсчёт часов.
