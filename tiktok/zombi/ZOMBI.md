# Пространство «Зомби»

Отдельный чат Claude для нового направления «Зомби» (тему и формат задаёт владелец). Общая память —
`CLAUDE.md` в корне репозитория: там все правила, стиль, метод промтов, озвучка, обложки. Здесь — коротко, что
скопировано и как этим пользоваться.

## Инструменты (`tools/`, копия рабочих скриптов «Наблюдателя», 15.11.2026)
| Файл | Что делает | Что поменять под новый ролик |
|---|---|---|
| `script.py` | сценарий `(№, [имена], текст)`, `**…**` — крупная фраза; `VOICE_FIX` — как читать цифры/латиницу | весь текст; `VOICE_FIX` |
| `prompts.py` → `PROMPTS.md` | промты Flow методом «Тихого места» (образцы R1–R5 + стиль сцены 01 + описание героев в каждой сцене), `ANIM` — промты Veo (не больше 5) | герои, образцы, сцены, анимации |
| `page.py` → `flow_page.html` | страница для телефона с кнопками «Копировать» (публиковать как Artifact) | заголовки, ключ `localStorage` |
| `fix_frames.py` | `frames_src/` → `frames/`, размывает читаемую «рыбу» на письмах/вывесках | `LETTERS` (координаты) |
| `voice_eleven.py --whole` | озвучка «Олегом» через API: **весь текст одной записью**, модель **eleven_v3** + `language_code=ru` (правильные ударения), **потоком** `/stream/with-timestamps` (обычный запрос прокси рвёт через 30 с) → `voice_user/vo.mp3` + `NN.json` (тайминг букв без распознавания) | ничего, голос `MWyJiWDobXN8FX3CJTdE` |
| `build.py --user` | сборка 1080×1920: заставка = обложка, субтитры по словам (Press Start 2P), крупные фразы, жёлтые имена, «рваная бумага», клипы Veo, громкость −14 LUFS | `TITLE`, `TITLE_WHITE`, `COVER_DATE`, `LABELS`, `TEAR_AT`, `CLIP_SPEED`, `CLIP_START`, имена файлов |
| `cover.py`…`cover4.py` | обложка и превью плитки профиля TikTok; утверждённый стиль — `cover4.var_A` («запись камеры наблюдения») | кадр (`cover4.SRC`), надписи в `build.cover_overlay` |
| `publish.py` | тексты публикации TikTok/YouTube → страница с кнопками | список роликов |
| `align_user.py` | если владелец пришлёт свою запись: распознавание → тайминг слов (STT ElevenLabs) | — |
| `fonts/` | Press Start 2P (субтитры, заставка), Handjet (пиксельный с кириллицей), Russo One, Oswald | — |

Для нового ролика: сделать папку (например `tiktok/zombi/<название>/`), скопировать туда `tools/` целиком и
поменять то, что в таблице. `build.py` и обложки ждут рядом `frames/`, `clips/`, `voice_user/`, `fonts/`.

## Порядок работы (проверено)
1. Сценарий → показать владельцу → тексты публикации.
2. Промты (образцы R1–R5, «Match the art style … of the attached scene image exactly», один цельный кадр,
   без коллажей) → страница для телефона.
3. Владелец генерирует во Flow (Nano Banana Pro, 9:16) и присылает пачками — номер сцены определять по картинке.
4. Анимации: не больше 5 клипов, Veo 3.1 Lite из готовой картинки, камера неподвижна.
5. Озвучка: `python3 voice_eleven.py --whole` (сам, подписка ElevenLabs Creator) → `python3 build.py --user`
   (рендер ~20 мин; запускать фоновой задачей, а не `nohup`, иначе оборвётся).
6. Обложка в утверждённом стиле, превью плитки со строкой просмотров.

Владелец пишет с телефона, по-русски, коротко. Перед большими тратами (кредиты, долгие сборки) — коротко сказать, что будет.
