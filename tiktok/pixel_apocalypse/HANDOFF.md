## Генерация через API PixelLab — ВКЛЮЧЕНА (пробный тариф: 40 генераций, на 01.11 после фонов и анимаций осталось 17)
- Клиент: `pixellab/api.py` (ключ подставляет сетевой прокси — секрет для api.pixellab.ai; в коде ключа нет).
- `backblaze.pixellab.ai` (storage_urls) заблокирован сетью → выгружать через `GET /characters/{id}/zip` (идёт с api.pixellab.ai).
- Персонаж v3 64px с нуля = 2 генерации. Стоимость остального смотреть в ответе `usage` / `GET /balance`.
- Палитра после героя и заражённого: 95 цветов при пределе 96 → фоны принимать с `--strict` или пересобрать палитру (k-means до ~80).
- Нужны домены `pixellab.ai`, `api.pixellab.ai` (может понадобиться ещё хост хранилища картинок — проверить по ответу API).
- Ключ: секрет сети для `api.pixellab.ai` либо переменная окружения `PIXELLAB_API_KEY` (Bearer). Никогда не просить ключ в чате.
- Сначала проверить доступ: документация API на `https://api.pixellab.ai/v2/docs` (или v1), затем пробный запрос.
- Все результаты — через `python3 pixellab/ingest.py` (масштаб, палитра, проверка стиля).

## Монтаж v4 (`video_v4.py`, звук `chiptune.py`)
`python3 video_v4.py part1|part2|full|covers` → `pixel_apocalypse_ep1_<part>.mp4`, обложки `cover_ep1_*.png`.
- Зацепка 1,6 с в начале (часть 1/полная: заражённый в проёме + «НЕ СМОТРИ В ОКНО»; часть 2: стук + «ЧАСТЬ 2»).
- Часть 1: озвучка 0 → «Правило номер два» (обрыв на «Я знаю, что ты там…»), карточка «ОТКРЫЛ БЫ? ЧАСТЬ 2 УЖЕ СКОРО».
- Часть 2: «Правило номер два» → конец, карточка «СЕРИЯ 2 · ЧУЖИЕ У ДВЕРИ».

- Palette cycling: огонь (night_street) и лампы мерцают сменой тёплых цветов палитры 10 раз/с.
- Субтитры 11 px, до 2 строк; крупный текст автоматически ужимается по ширине кадра.
