# PIXEL APOCALYPSE — состояние проекта (для новой сессии)

Ветка: `claude/apocalypse-tiktok-video-mixv1u`. Язык общения с владельцем — русский.
Канал TikTok про выживание в апокалипсисе, вертикальные видео 1080×1920 под озвучку (ElevenLabs).

## Главные решения (согласованы с владельцем)
- Стиль зафиксирован в `STYLE_LOCK.md` — **v3, PixelLab, вариант А (бесплатный тариф)**:
  кадр 108×192 арт-пикселей, пиксель 10×10, фоны 162×192, персонажи 64px (Sidescroller).
- Палитра — `pixellab/palette_master.json`, собирается из одобренных ассетов (`ingest.py`, слияние < 8, предел 96).
- Генерация — только PixelLab. Монтаж, камера, частицы, субтитры (пиксельный шрифт), звук — наш код.
- Старая процедурная версия (пиксель 6×6) — архив: `frames_v2/`, `frames_v3/`, `video.py`, `pixel_apocalypse_ep1.mp4`.

## Серия 1 «72 ЧАСА»
- Озвучка `tiktok/series/voice.mp3`, тайминги фраз `tiktok/series/timings.json` (по паузам, `align.py`),
  звуковая дорожка (голос + музыка + SFX) — `episode1.make_audio()`.
- Раскадровка 27 планов — `video.py` (SHOTS), её надо перенести на сетку v3 и ассеты PixelLab.

## Готовые ассеты PixelLab (`pixellab/assets/`)
| Ассет | Что | Холст | Ступни (нижняя строка) |
|---|---|---|---|
| `hero_rot/000–007` | герой, 8 ракурсов (S, SE, **E=002**, NE, N, NW, W, SW) | 64×64 | y=62 |
| `hero_walk/000–007` | ходьба вправо, Skeleton v3 «Walking (8 frames)» | 96×96 | y=78 |

Ходьба: 8 кадров/с, скорость 36 арт-пикселей/с (опорная нога ≈4,5 px/кадр) — ноги не скользят.
Проба: `pixellab/preview_walk.mp4`.

## Генерация через API PixelLab (если владелец включил)
- Нужны домены `pixellab.ai`, `api.pixellab.ai` (может понадобиться ещё хост хранилища картинок — проверить по ответу API).
- Ключ: секрет сети для `api.pixellab.ai` либо переменная окружения `PIXELLAB_API_KEY` (Bearer). Никогда не просить ключ в чате.
- Сначала проверить доступ: документация API на `https://api.pixellab.ai/v2/docs` (или v1), затем пробный запрос.
- Все результаты — через `python3 pixellab/ingest.py` (масштаб, палитра, проверка стиля).
