# STRICT VISUAL STYLE LOCK — PIXEL APOCALYPSE

Сверяться с этим документом перед каждой новой сценой. Эталон — `frames_v2/` и `frames_v2/characters_sheet.png`.

## Стиль
16-BIT RETRO PIXEL ART / DARK POST-APOCALYPTIC RPG — кадр выглядит как скриншот старой 16-битной игры
(вид сбоку, как в 2D-RPG/адвенчуре), а не как цифровая иллюстрация.

## Зафиксированная техника (менять нельзя)
| Параметр | Значение | Где задано |
|---|---|---|
| Формат | 9:16, 1080×1920 | `pixel2.OUT_W`, `CW/CH` |
| Холст кадра | 180×320 арт-пикселей | `pixel2.CW, CH` |
| Размер пикселя | 6×6, nearest neighbor, без сглаживания | `Scene.save` |
| Мир сцены | 270×480, кадр — «камера» внутри него | `pixel2.W, H` |
| Палитра | 47 фиксированных цветов (ниже), других нет | `pixel2.PALETTE` |
| Тени и свет | только ступени палитры + упорядоченный дизеринг Bayer 4×4 | `Scene.render` |
| Освещение | зелёный эмбиент + тёплые точечные источники с кольцевым ореолом; без 3D-освещения | `Scene.add_light` |
| Контуры | чёрный внешний контур 1 px у персонажей и предметов, выборочный контур между деталями | `characters.SpriteBuilder` |
| Персонажи | ~106 px роста стоя, 4 тона на материал, пиксельные лица без реализма | `characters.py` |
| Яркие акценты | O3/O4/R4/R5/E2 — только лампы, огонь, глаза; ≤ 4% кадра | `check_style.py` |

### Палитра
- Charcoal black / dark olive green: `G0–G8`, `M0–M3`
- Rust red: `R0–R5`
- Faded orange: `O0–O4` (O3/O4 — только источники света)
- Dirty brown: `B0–B3`, `H0–H2`
- Muted grey: `P0–P4`, `E0–E2`
- Кожа (приглушённая): `S0–S3`; заражённые: `Z0–Z3`

## Мир
Разрушенные многоэтажки, брошенные машины, разбитые окна, заброшенные магазины, военные блокпосты,
разрушенные дороги, лес, поглощающий город, убежища и подземелья.

## Можно менять
Место действия, персонажей, предметы, время суток, сюжетные события.

## Нельзя
Фотореализм, 3D, цифровую живопись, аниме, вектор, мягкие градиенты, размытые пиксели,
«фото с пиксельным фильтром», смену техники/размера пикселя/палитры между сценами,
надписи, интерфейс, водяные знаки.

## Автопроверка
```
python3 check_style.py frames_v2/*.png
```
Проверяет: 1080×1920; кадр целиком из одноцветных блоков 6×6; все цвета — из палитры; доля ярких акцентов ≤ 4%.
Кадр, не прошедший проверку, переделывается.
