# STRICT VISUAL STYLE LOCK — PIXEL APOCALYPSE

Сверяться с этим документом перед каждой новой сценой.
**Действующая версия — v3 «PixelLab, вариант А»** (выбрана владельцем канала). Эталон героя —
`pixellab/assets/hero_rot/` (сгенерирован в PixelLab). Версия v2 (процедурная, пиксель 6×6) — ниже, как архив.

## Стиль
16-BIT RETRO PIXEL ART / DARK POST-APOCALYPTIC RPG — кадр выглядит как скриншот старой 16-битной игры
(вид сбоку, как в 2D-RPG/адвенчуре), а не как цифровая иллюстрация.

## Зафиксированная техника v3 (менять нельзя)
| Параметр | Значение | Где задано |
|---|---|---|
| Формат | 9:16, 1080×1920 | `check_style.SIZE` |
| Кадр | **108×192** арт-пикселей | — |
| Размер пикселя | **10×10**, nearest neighbor, без сглаживания | `check_style.MODE` |
| Фон сцены | **162×192** (камера 108×192 ездит вбок целыми пикселями) или 108×192 | `pixellab/ingest.BG_SIZES` |
| Персонажи | PixelLab Character Creator v3, **Sidescroller, 64px**, Highly detailed; герой ~62 px роста (≈⅓ кадра) | `PIXELLAB_GUIDE.md` |
| Палитра | **главная палитра** из одобренных ассетов PixelLab, ≤ 96 цветов; близкие цвета (< 8) сливаются | `pixellab/palette_master.json` |
| Семейства цветов | тёмная олива, приглушённый серый, грязно-коричневый, угольно-чёрный, ржавый красный, выцветший оранжевый (+ приглушённая кожа) | — |
| Контуры | чёрный внешний контур у персонажей | PixelLab Outline |
| Яркие акценты | яркие насыщенные цвета — только огонь, лампы, глаза; ≤ 4% кадра | `check_style.py` |
| Генерация | только PixelLab; ассеты принимаются через `pixellab/ingest.py` | — |

## Мир
Разрушенные многоэтажки, брошенные машины, разбитые окна, заброшенные магазины, военные блокпосты,
разрушенные дороги, лес, поглощающий город, убежища и подземелья.

## Можно менять
Место действия, персонажей, предметы, время суток, сюжетные события.

## Нельзя
Фотореализм, 3D, цифровую живопись, аниме, вектор, мягкие градиенты, размытые пиксели,
«фото с пиксельным фильтром», смену техники/размера пикселя/палитры между сценами,
надписи, интерфейс, водяные знаки.

## Автопроверка
```
python3 check_style.py КАДРЫ...            # v3: пиксель 10×10, главная палитра
python3 check_style.py --legacy КАДРЫ...   # архив v2: пиксель 6×6, палитра pixel2
```
Проверяет: 1080×1920; кадр целиком из одноцветных блоков; все цвета — из палитры; доля ярких акцентов ≤ 4%.
Кадр, не прошедший проверку, переделывается.
