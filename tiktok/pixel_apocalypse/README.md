# PIXEL APOCALYPSE — визуальный стиль канала

16-bit dark pixel art. Кадры рисуются кодом (`pixel.py` — движок, `test_frames.py` — сцены),
поэтому стиль не «плывёт» от кадра к кадру.

## Правила стиля (зашиты в движок)
- Холст **216×384**, увеличение **×5 nearest neighbor** → 1080×1920 (9:16). Один пиксель арта = 5×5 px, без сглаживания.
- **Фиксированная палитра из 28 цветов**, 5 рамп: чёрный→серый (K0–K6), тёмно-зелёный (N0–N5),
  грязно-коричневый (B0–B5), приглушённый красный (R0–R3), тусклый оранжевый (O0–O4). Других цветов нет.
- Градиенты, свет и тени — только **упорядоченный дизеринг Bayer 4×4**.
- Свет: тёплый (огонь, свеча, лампа) окрашивает серое в коричневое → оранжевое; лунный — в холодный серый.
- Все объекты и персонажи с тёмным контуром в 1 пиксель, освещение сбоку, виньетка по краям.
- Персонажи всегда в масштабе `K = 1.6` (~100 px арта по высоте).
- **Никакого текста на кадрах** — надписи накладываются при монтаже.

## Герой
Зелёная парка с капюшоном, противогаз с тускло-оранжевыми стёклами, коричневый рюкзак со скаткой,
**красный шарф** (узнаваемый акцент), серые штаны, чёрные ботинки.

## Заражённые
Сутулые, длинные руки, серо-зелёная кожа, рваная коричневая одежда, два тусклых красных глаза.

# v2 — «бункерный» стиль (по референсу)

`pixel2.py` + `test_frames2.py` → `frames_v2/`. Ориентир — тёмный 2D side-view пиксель-арт:
зелёная гамма, каменная кладка с подсвеченными гранями, ржавые трубы с фланцами, провисшие кабели,
паутина, лампы в клетке с кольцевым ореолом, решётчатый пол.

- Мир сцены 270×480, «камера» 180×320 → ×6 = 1080×1920.
- Сцена освещается в полном цвете (зелёный эмбиент + тёплые лампы), затем квантуется в палитру из 42 цветов с дизерингом Bayer.
- Персонажи — ручной попиксельный ASCII-арт (`HERO_STAND`, `HERO_SIT`, `ZOMBIE`), всегда читаемы на тёмном фоне.
- Герой: тёмные волосы, красная куртка с высоким воротом, оливковый рюкзак, серые штаны.

### Персонажи v2.1 (`characters.py`)
Рост героя ~106 px арта (≈⅓ кадра). Спрайт собирается из частей тела и одежды, у каждого материала
4 тона, выборочный контур между деталями, внешний чёрный контур и ручные детали: бровь, глаз, щетина,
молния, карман, ремень с подсумком, наколенник, шнуровка. Позы: `hero_stand()`, `hero_stand(pipe=True)`,
`hero_sit()`, `zombie()`. Лист персонажей: `python3 characters.py` → `frames_v2/characters_sheet.png`.
