# Апокалипсис — TikTok (9:16, 1080×1920, 24 с)

`apocalypse_tiktok.mp4` — готовый ролик. Пересобрать: `python3 tiktok/apocalypse/generate.py`
(нужны numpy, Pillow, ffmpeg; графика и звук генерируются процедурно — без чужих материалов).

| Время | Сцена | Звук |
|---|---|---|
| 0–4 с | ⚠ Экстренное оповещение, глитч: «ВСЕМ ЖИТЕЛЯМ НЕМЕДЛЕННО ПРОЙТИ В УКРЫТИЯ» | сирена ГО, EAS-сигнал |
| 4–8.5 с | Вечерний город: «Нам сказали: „это просто учения“» → «Мы поверили.» | ветер, мрачная мелодия |
| 8.5–13 с | Вспышка, ядерный гриб, тряска, пепел: «06:17», «Небо стало белым.» | взрыв, рокот, звон в ушах |
| 13–19 с | Пустошь, выживший в противогазе, дозиметр: «ДЕНЬ 347. Я всё ещё жив.» | ветер, счётчик Гейгера |
| 19–24 с | Радиопомехи, 147.3 МГц: «Если ты это слышишь — ты не один.» «☢ ПОДПИШИСЬ — чтобы выжить» | статика, морзянка |

Подпись для поста: `День 347. Если ты это видишь — выходи на связь 📻☢️ #апокалипсис #постапокалипсис #выживание #fyp`
