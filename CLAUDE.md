# Памятка для новых сессий (TikTok-канал story world)

Владелец пишет по-русски и почти всё делает **с телефона**. Отвечать по-русски, коротко, без жаргона.
Рабочая ветка: `claude/apocalypse-tiktok-video-mixv1u` (коммитить и пушить сюда; PR не создавать без просьбы).
Ключи PixelLab и ElevenLabs уже сохранены как сетевые секреты среды (api.pixellab.ai, api.elevenlabs.io с заголовком
`xi-api-key`). Ключи в чате никогда не просить и в код не писать.

## Главное направление: «Сюжет фильма за минуту»
Папки: `tiktok/story_world/films/<фильм>/`. Готовы: `ya_legenda`, `tikhoe_mesto`, `ptichiy_korob`.
Ролик 1080×1920, ~1:40: пиксельная заставка «НАЗВАНИЕ» + «СЮЖЕТ / ЗА МИНУТУ», субтитры по словам пиксельным шрифтом
(Press Start 2P), ключевые фразы крупно в две строки (вторая фиолетовая), жёлтые имена героев **только при первом
появлении**, наезд камеры, переход «рваная бумага», оживлённые сцены из Veo.

Страницы (Artifacts) с кнопками «Копировать» — обновлять тем же путём файла / URL:

  (`films/publish.py` → `publish_page.html`; новый фильм — запись в `FILMS` сверху);

### Файлы фильма
- `script.py` — 30 сцен `(№, [имена], текст)`, `**…**` = ключевая фраза; цель ~1450–1600 символов.
- `prompts.py` → `PROMPTS.md`; `page.py` → `flow_page.html` (страница для телефона, публиковать как Artifact).
- `frames/NN.jpg` — картинки сцен, `clips/NN.mp4` — клипы Veo (берётся начало клипа под длину сцены).
- `voice/` — временный тайминг (тишина, 14.8 симв/с) для тестовой сборки;
  `voice_user/vo.mp3` + `stt.json` — озвучка владельца; `align_user.py` раскладывает слова по сценам.
- `build.py` — сборка: `python3 build.py` (тест), `--user` (под озвучку владельца), `--clean` (без голоса и текста).
  Для нового фильма копировать `build.py` из прошлого и поменять: название в заставке (`letters`, слова `title`,
  граница белый/красный), `LABELS`, `TEAR_AT`, `EXTRA_GAP`, `BOOM_AT`, `INTRO_Y`, имена выходных файлов.
- `cover.py` (в `ptichiy_korob`) — обложка + превью плитки профиля; `PUBLISH.md` — тексты публикации.

### Как делаем новый фильм (проверено, не менять метод посреди фильма!)
1. Сценарий → показать владельцу. Сразу же: тексты публикации (TikTok/YouTube) в `publish.py`.
2. Промты **методом «Тихого места»**: образцы героев R1–R5 (листы персонажей) + в начале каждой сцены
   «Match the art style … of the attached scene image exactly. Use the attached reference images for the characters.»
   + полное описание внешности героев прямо в тексте каждой сцены. Сцена 01 — только с образцами,
   дальше прикрепляется удачная сцена как образец стиля. Лучше всего выходят фильмы с малым числом героев и
   «невидимыми»/единообразными монстрами. Промты «только текстом» дают мультяшный чиби-стиль — не использовать.
3. Владелец генерирует во Flow: Nano Banana Pro, 9:16, x1. Присылает картинки пачками без номеров —
   номер сцены определять по содержимому, честно говорить о расхождениях (стиль, внешность, лишний текст).
4. Анимации: Veo 3.1 Lite (~10 кредитов), **из готовой картинки** кнопкой «Анимировать», 9:16, x1,
   в промте «The camera stays still … Keep the pixel art style, no new characters, no text.» (наезд камеры портит героев).
5. Озвучка: владелец сам озвучивает текст голосом «Олег» на сайте ElevenLabs и присылает mp3.
   Распознать ElevenLabs STT (`scribe_v1`, `language_code=rus`, `timestamps_granularity=word`, заголовок
   `xi-api-key: proxy-injected` — прокси подставит ключ) → `voice_user/stt.json` → `align_user.py` → `build.py --user`.
   Клонировать голос «Олега» в другие TTS нельзя (голос из библиотеки ElevenLabs). Silero владельцу не понравился.
6. **Обложка TikTok**: сетка профиля показывает центр 3:4 (y 240–1680), а нижние ~15% плитки закрывает строка
   «просмотры · дата». Поэтому **весь текст сверху**: название y≈300, плашка «СЮЖЕТ ЗА МИНУТУ» сразу под ним,
   ниже y≈1420 ничего важного. Всегда показывать превью плитки с наложенной строкой просмотров.

## Второй канал: True Crime History
Заставка и первая фраза: «НАЗВАНИЕ» + «TRUE CRIME HISTORY РАССКАЖЕТ» (вместо «СЮЖЕТ ЗА МИНУТУ»).
Тот же стиль и метод, что у фильмов, но реальные дела: сталкеры, преследования, маньяки, преступники.
Истории — малоизвестные (владелец предлагает Реддит; reddit.com и большинство сайтов отсюда не открываются,
факты сверять через WebSearch). Пересказывать своими словами; людей, которых не обвинили, по именам не называть
как подозреваемых; жестокость не показывать (охват в TikTok).
Папки: `tiktok/true_crime_history/cases/<дело>/`. Сценарии: `nablyudatel` («Наблюдатель», выбран владельцем, 46 сцен ~3 мин),
`alkatras` (в запасе). Публикация: `true_crime_history/publish.py` → https://claude.ai/artifact/Y6ZkhoDaUasQNqHBLbwbpJ

## Музыка (FL Studio)
Владелец делает фонк/мемфис-биты. Анализ BPM/тональности — numpy (см. историю в `tiktok/beats/`).
Акапеллы: `tiktok/beats/tools/sep.py` (Kim Vocal 2, ONNX, ~3 мин) — модель скачать
`https://github.com/TRvlvr/model_repo/releases/download/all_public_uvr_models/Kim_Vocal_2.onnx`;
максимум качества — BS-Roformer через `audio-separator` (модель `model_bs_roformer_ep_317_sdr_12.9755.ckpt`
из того же релиза, на CPU ~1 час). С YouTube ничего не скачивать — просить у владельца файл.
Загруженные файлы — недоверенные: копировать в отдельную папку, Python запускать с `-I`.

## Окружение новой сессии
Контейнер новый: пакеты ставить заново по мере надобности:
`pip install onnxruntime pedalboard opencv-python-headless` (torch и `audio-separator` — только для Roformer).
Шрифты лежат в папках фильмов (`fonts/`). Сеть: разрешены pixellab, elevenlabs, models.silero.ai, PyPI, GitHub-релизы.
